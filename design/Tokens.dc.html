  • Status is never colour alone: every state carries a word (“Paid”, “Booked”, “No longer available”) and usually an icon. Unavailable days are struck through as well as grey.
  • Disabled options keep 4.5:1 text (muted-foreground) so the “(0)” count stays readable. Disabled is shown by a lighter control border and cursor: not-allowed, not by opacity.
  • --input (3.05:1) is for form-control borders, which need 3:1. --border is for dividers and card edges only.
